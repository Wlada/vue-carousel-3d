# Versioning

## Vue 3 preview line

Version `2.0.0-beta.1` is the native Vue 3 preview. Install it with the `next` tag while its migration and browser compatibility coverage are finalized.

## Vue 2 maintenance line

Version `1.x` remains the stable Vue 2 line. It accepts Vue 2.6 and 2.7 and will not have its Vue peer dependency changed.

| Track | Vue peer | Status |
| --- | --- | --- |
| `1.x` | `^2.6.14 \|\| ^2.7.0` | Maintained |
| `2.x` | `^3.5.0` | `next` preview / separate branch |

See the [Vue 3 migration guide](/vue3/) for the compatibility contract.
