# Versioning

## Vue 2 maintenance line

Version `1.x` remains the stable Vue 2 line. It accepts Vue 2.6 and 2.7 and focuses on packaging, browser compatibility, accessibility and documented bug fixes.

## Vue 3 line

The Vue 3 port will live on a separate branch and major version. It will not silently change the peer dependency of the Vue 2 package.

| Track | Vue peer | Status |
| --- | --- | --- |
| `1.x` | `^2.6.14 \|\| ^2.7.0` | Maintained |
| `2.x` | Latest Vue 3 | Planned / separate branch |

See the [Vue 3 roadmap](/vue3/) for the intended migration contract.
