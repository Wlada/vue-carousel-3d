## 仍然支持的内容

- Vue `^2.6.14` 与 `^2.7.0`
- `<carousel-3d>` 与 `<slide>` 全局或局部注册
- ESM、CommonJS 与 UMD 软件包入口
- 无障碍访问、浏览器兼容性与已记录在案的缺陷修复发布
