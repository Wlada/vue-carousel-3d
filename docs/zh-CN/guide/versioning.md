# 版本策略

## Vue 3 发布版本线

`2.0.0` 版本是原生 Vue 3 版本线，并以默认的 `latest` 版本发布。

## Vue 2 维护版本线

`1.x` 版本仍是稳定的 Vue 2 版本线。它支持 Vue 2.6 与 2.7，并且不会改变其 Vue 同级依赖。

| 版本线 | Vue 同级依赖 | 状态 |
| --- | --- | --- |
| `1.x` | `^2.6.14 \|\| ^2.7.0` | 维护中 |
| `2.x` | `^3.5.0` | 当前（默认） |

兼容性契约请参见 [Vue 3 迁移指南](/zh-CN/vue3/)。

[Vue 2 归档](/zh-CN/v1/) 在 Vue 3 文档成为默认站点之后，仍会保留 `1.x` 版本的安装指南、示例与 API 参考。
