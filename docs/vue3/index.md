# Vue 3 roadmap

The Vue 3 version will be developed on a separate branch after the Vue 2 maintenance release is stable.

## Contract

- Native Vue 3 components and plugin registration.
- Latest stable Vue peer dependency at release time.
- Equivalent core props, events and visual behavior where practical.
- A migration table for every renamed or removed API.
- Dedicated unit, SSR and real-browser coverage.

The current `1.x` package remains the Vue 2 track. Do not upgrade across the future major version without reading the migration guide.
